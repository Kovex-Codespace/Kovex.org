サンプル:

コードを書き換えて ▶ 実行 を押すと、その場でプログラムが動きます。 ゲームのサンプルでは、ステージをクリック／タップすると勇者が移動し、スペースキーまたは攻撃ボタンで攻撃できます（キーボード操作はエディタの外をクリックしてから）。 パックマンのサンプルでは、矢印キー／WASD・画面の十字キー・ステージ上のスワイプで移動し、Pで一時停止、Rでリスタートできます。 新機能ラボは、色・形の指定、リスト／辞書、関数とスコープ、壁と穴（経路探索で回避）、任意キー入力、HUDとボタン、名前で変わるサウンドを全部使ったサンプルです。 実ファイル対応：下の「素材ファイル」で画像・音声を選ぶか、コードにURLを直接書くと、sprite・background・play bgm / play sound で実際のファイルが表示・再生されます（ファイル名だけの指定は、従来どおり内蔵シンセ／絵文字として扱います）。

素材ファイル（実ファイル）: まだ読み込んでいません。選んだファイルは、そのファイル名のまま sprite = "hero.png" / play bgm "song.mp3" のようにコードから指定できます。URLを直接書いても読み込めます（このページを開いている間だけ有効です）。

コンソール
    変数・アクター

    実行すると、live 変数やステージ上のアクターのHPがここにリアルタイム表示されます。

    このプロトタイプで使える Omnia の文法（チートシート）

    say "文字" + 変数 … コンソールへ出力します

    x = 10 / x += 5 … 代入と計算（+ − × ÷、比較、and / or / not）

    live hpBar = hp / 100 … 元の値が変わると自動で再計算される値です

    when hp <= 0 { … } … 条件が真になった瞬間に実行される監視ブロックです

    scene Field { … } … シーン定義。定義だけの場合は最初のシーンが自動で始まります

    actor Slime { hp = 30 } … アクター（キャラクター）の型を定義します

    spawn Slime x5 / spawn Hero at (3, 8) … 出現させます

    brain = chase Player within 12m … NavMesh風の自動追跡。壁がある場所では経路を自動で探して避けます

    when touchedBy Player { … } … 触れられたときのイベントです

    drop Wood x2 / vanish / hop back 1m … アクター用の命令です

    wait 2s -> fadeOut title … タイムライン記法。待ってから次の命令へつなぎます

    narande { … } -> wait all … 中の命令を並行して動かします

    if 条件 { … } else { … } / for i in 1..5 { … } … 分岐と繰り返しです

    show title "題名" / fadeOut title … ステージ上にタイトルを表示します

    play bgm "https://…/song.mp3" … URL、または素材パネルで読み込んだファイル名を指定すると、実際の音声ファイルをループ再生します。ファイル名だけ（例 "field.mp3"）のときは、名前で曲調が変わる簡易シンセ演奏になります

    rand(1, 6) など … 組み込み関数: rand / floor / round / abs / min / max

    命令 ~> onFail { … } … 失敗したときの分岐（エラー時に右側を実行）です

    pacman … パックマンを開始します（scene の中で書きます。矢印キー／WASD／十字キー対応）

    color = "#ff5a5a" / shape = "star" … アクターの見た目をコードで指定します（shape は circle / square / triangle / diamond / star、size = 1.4 で大きさ、sprite = "💎" で絵文字スプライトも使えます）

    sprite = "https://…/hero.png" … 画像のURL、または素材パネルで読み込んだ画像ファイル名を指定すると、その画像をそのままスプライト表示します（image = "…" でも同じです。読み込めない場合は図形で代用します）

    background = "https://…/bg.jpg" … scene の中で書くと、ステージの背景にその画像を表示します（素材パネルの画像ファイル名でも指定できます）

    hud 名前 = "スコア: " + score at (14, 12) size 22 … ステージ上の好きな位置に、値が自動更新される文字を表示します（座標は 900×600 基準のピクセル）

    button 名前 "攻撃" at (716, 516) { … } … クリックできるボタンをステージ上に置き、中の処理を実行します

    play sound "https://…/se.mp3" … URL、または素材パネルで読み込んだファイル名を指定すると、実際の効果音ファイルを再生します。ファイル名だけのときは名前で音色が変わるシンセ音になります（coin / jump / shoot / hit / heal / power / die / explosion など）。読み込みに失敗した場合はシンセ音へ自動で切り替わります

    list = [1, 2, 3] / dict = {wave: 1} … リストと辞書。list[0]、dict.wave、dict["wave"] で読み書き、push(list, 値) / pop(list) / len(list) が使えます

    fn 加算(a, b) { return a + b } … ユーザー定義関数。引数と let で作った変数は関数の中だけのスコープです

    let x = 1 … ブロックの中だけ有効な変数を作ります。for のループ変数もそのブロック内だけ有効で、外の同名変数を上書きしません

    for item in list { … } … リストの中身を1つずつ取り出して繰り返します（1..5 の範囲指定も従来どおり使えます）

    wall at (5, 3) / wall rect (2, 2, 6, 1) / hole at (7, 7) … 通れない地形を置きます。chase の追跡は壁を避ける経路を自動で探します

    when touchedBy X { … } … chase の有無にかかわらず、すべてのアクター同士の接触で発火します（壁役・罠・弾・アイテムにも使えます）

    when key "e" pressed { … } … 任意のキー入力をコードで受け取ります。key("space") で押されている間ずっと真になる判定もできます
