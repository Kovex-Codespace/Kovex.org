01 — ABOUT

Kovexとは何をしているグループか

ひとことで言えば「作る・公開する・届けるの壁を取り払う」テクノロジーグループです。ゲーム、AIモデル、言語とツール、プラットフォーム、オープンソース公開——分野を横断して自分たちで作り、世界へ開いています。ゲームだけの会社ではありません。

01

ゲーム開発GAME DEVELOPMENT

RPG、3Dオープンワールド、攻城戦、クイズバトルロイヤルまで、ジャンルを固定せずに実験と完成を繰り返すのがKovexの作り方です。『ETERNALOCCASION IV』『OPEN FRONTIER』『CASTLE SIEGE 4』など、大規模タイトルも単一HTMLで軽く動く形に仕上げる軽量化の工夫が強みです。

02

プラットフォーム運営PLATFORM — G-HUB

作ったゲームが誰にも届かなければ意味がありません。そこで生まれたのが、ダウンロード不要・アカウント不要で1タップ即プレイできるブラウザゲームプラットフォーム「G-HUB」。投稿・ランキング・コミュニティまでを備え、誰かの「作った！」がすぐ誰かの「遊んだ！」になります。

03

言語とツールの開発LANGUAGE — OMNIA

「もっと簡単にゲームを作れたら」という発想から生まれたのが、ゲーム特化プログラミング言語 Omnia です。世界の言語の良いところだけを取り入れ、Unityに近い表現力・自動の軽量化・簡単な共有を目指して設計されました。ブラウザ上の実行環境で、書いたその場でゲームが動き出します。

04

AIモデル開発AI — OMNI-CORE-AGENT

ゲームの外へ踏み出した柱が、AIモデルの開発です。画像とテキストを扱うマルチモーダルモデル 「Omni-Core-Agent」（Image-Text-to-Text／10B） を開発し、AIの公開プラットフォーム Hugging Face で世界へ公開しています。作って終わりではなく、誰もが試せる形で届けるのがKovexのやり方です。

05

オープンソース公開OPEN SOURCE — GITHUB / HUGGING FACE

コードとモデルは、閉じずに開く。開発の拠点 GitHub（Kovex-Codespace） では Omnia、Kovex公式サイト、Omni-Core-Agent の公開リポジトリを、Hugging Face ではAIモデルを公開しています。オープンにすることで、学ぶ人・作る人・使う人が世界中から集まる土台をつくります。

03 — LANGUAGE

Omnia — ゲームのためだけに生まれた言語

読み方は「オムニア」。先行案「Toki」を発展させた、KovexGroup開発のゲーム特化プログラミング言語です。

Omniaの設計条件は最初から決まっていました。ゲームに強いこと、世界のすべての言語の利点だけを取り入れること、Unityとほぼ同じ機能が使えること、自動で軽量化されること、簡単に共有できること。その答えとして、シーンとアクターを宣言するだけで世界が立ち上がり、brain = chase の一行で敵が追いかけてくる——そんな言語になりました。

  • a.
    宣言するだけで動くscene / actor / spawn で舞台と登場人物を用意し、live で毎フレームの振る舞いを書きます。
  • b.
    出来事は when でつなぐwhen touchedBy（触れたら）、when key（キー入力）など、ゲーム特有の出来事がそのまま文法になっています。
  • c.
    時間と並行を言葉で書くwait -> のタイムライン、同時進行の narande、失敗分岐の ~> onFail で、演出も失敗処理も読みやすく。
  • d.
    本格的な道具もそろうリスト・辞書、fn 関数と return、let とスコープ、壁・穴の地形と壁回避（BFS）、画像・音声素材の読み込み、BGMループまで対応。
  • e.
    ブラウザ実行環境ですぐ試せるシンタックスハイライト付きエディタで .omni コードを実行でき、右側の2Dステージで結果がそのまま遊べます。サンプルは「パックマン」を含む6種＋文法チートシート付き。
sceneactorspawnbrain=chasewhenwhen touchedBylivewait ->narande~> onFailif / forfn / returndrop / vanishplay bgm
chase.omni 

          

          

            

              ▶ ライブデモ：brain = chaseステージをクリック／タップすると勇者が移動し、スライムが追いかけます
              
            

            
            
これはOmnia実行環境のステージを再現したミニデモです。勇者に触れるとスライムが跳ね返ります（when touchedBy のイメージ）。
